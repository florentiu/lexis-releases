# Lexis releases

Public binary distribution mirror for the [Lexis](https://lexis.dev) search
engine. Source code lives in a private repository.

## Install

**macOS / Linux** — Homebrew:

    brew tap florentiu/lexis
    brew install lexis

**Windows** — download the `.zip` from the [latest release][r], extract `lexis.exe`.

**Docker** — `docker run -d -p 5391:5391 ghcr.io/florentiu/lexis:latest`

[r]: https://github.com/florentiu/lexis-releases/releases/latest
